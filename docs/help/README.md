# Sekcje pomocy WallDecor Portal

Ten katalog zawiera operacyjne instrukcje dla trzech ról w portalu:

- [ARCHI](./archi.md) - panel architekta, projekty, portfel, cashback i wypłaty prowizji.
- [STAFF](./staff.md) - obsługa architektów i projektów bez dostępu do operacji finansowych.
- [ADMIN](./admin.md) - pełna administracja, rozliczenia, backup, ustawienia i kontrola po wdrożeniu.

Treści są napisane jako materiał do publikacji w sekcji pomocy albo do wykorzystania w onboardingowych mailach/procedurach. Nie zastępują checklisty wdrożeniowej: przed deployem produkcyjnym użyj [DEPLOY-P1-CHECKLIST.md](../../DEPLOY-P1-CHECKLIST.md).

## Utrzymanie

Jeśli zmieniamy UX, nazwy przycisków, ścieżki w panelu, statusy, uprawnienia ról albo logikę funkcjonalną portalu, odpowiednie instrukcje w tym katalogu muszą zostać zaktualizowane w tym samym pakiecie zmian. Dokumentacja pomocy powinna opisywać aktualne zachowanie produkcyjnej aplikacji, a nie wcześniejszy przebieg procesu.
